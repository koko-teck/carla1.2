BEAUTY STYLIST — OPCIÓN VISUAL 03

Dirección visual: quiet luxury / editorial beauty.

SE CONSERVA SIN CAMBIOS:
- Nombre BEAUTY STYLIST.
- Logotipo y archivo de logo.
- Servicios.
- Productos.
- Imágenes del catálogo.
- Imágenes de transformaciones/presentación.
- Video de presentación.
- Funciones existentes (búsqueda, compartir, WhatsApp, Instagram, Facebook, aviso de trabajos a domicilio).

CAMBIO PRINCIPAL:
Se agrega una tercera propuesta visual mediante overrides CSS: fondos marfil, espresso, champagne y rosa empolvado, pensados para armonizar con el logotipo.

REDES SOCIALES:
Los botones flotantes muestran SOLO el icono/logo de WhatsApp, Instagram y Facebook. El texto completo se conserva únicamente en aria-label/title para accesibilidad.

NO HACE FALTA CAMBIAR LAS IMÁGENES: se conservan las mismas referencias y archivos del proyecto anterior.
